## How to use

### Cursor

```bash
cp -r code-review ~/.cursor/skills/
```

### Claude Code

```bash
cp -r code-review ~/.claude/skills/
```

### OpenAI Codex

```bash
cp -r code-review ~/.codex/skills/
```

### GitHub Copilot

```bash
cp -r code-review ~/.copilot/skills/
# Or place in project directory
cp -r code-review .github/skills/
```
